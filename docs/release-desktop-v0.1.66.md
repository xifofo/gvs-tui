# TUI v0.2.64 / Desktop v0.1.66

配套网关 v3.9.81，补齐腾讯 TV 自动画像注册响应的诊断与显示。

- 注册请求收到 HTTP 200、业务码 0，但设备身份未确认时，显示“注册响应未确认”，不再笼统显示为风控/请求拒绝。
- 诊断区分响应格式、解密、身份缺失和身份字段不唯一；仅记录固定分类、HTTP 状态和业务码，不保存响应明文、注册身份或密钥。
- 未确认或送达不确定时保持当前流程停止，不自动重发，不清除原注册账本。
- 保留前版优酷登录/会员/整集完整性检查、腾讯搜索进入详情及其他平台修正。

验证：客户端库全量 856 项通过、20 项按条件跳过、0 失败；其中 45 项腾讯客户端、诊断及账号业务流程测试通过；桌面类型检查、Electron 构建通过；配套网关注册响应解析、加密账本持久化与不重发测试通过。

本版本补齐定位能力，未将 HTTP 200/code=0 当成身份注册成功。当前已发送请求尚未确认 Qimei 身份，广告画像缺 qimei36 的问题仍待取得对应响应诊断后继续处理。升级不会自动重试已有 blocked/rejected/delivery_unknown 记录。

Windows 安装包及 macOS arm64/x64 安装包由 desktop-v0.1.66 发布页提供。TUI 从 v0.2.64 标签源码安装。发布不等于远程运行的网关进程已升级。
