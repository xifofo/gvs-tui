# Desktop 0.1.18

IQ 下载遇到 CDN 502 或连接提前结束后，之前的客户端重试会删除已经下载的分片。现在按片源、分片路径与范围、时间轴和密钥的摘要校验缓存，再继续下载缺失分片；不一致的缓存保留但不混用。旧版缓存只有清单和全部密钥通过校验后才接入续传。短暂 CDN 故障会刷新链接并续传，最多自动恢复两次，仍失败时保留缓存供再次继续。

视频完成后独立音轨或字幕失败，再次继续可以复用已经校验完成的视频。任务行区分视频下载与真正的最终合并。

3840×1608 等宽屏片源显示为 4K，保留实际像素尺寸；历史 IQ 任务中已有的 1608P 标签一并修正。

验证：IQ、缓存身份与分片进度测试通过，TUI 与桌面类型检查、构建通过。真实下载结果另见本地验收记录，测试通过不等于远程媒体已经完整下载。
