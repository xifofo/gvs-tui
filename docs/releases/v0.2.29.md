# TUI v0.2.29 / 桌面端 desktop-v0.1.24

配套网关：v3.9.36。先更新网关，再更新客户端；旧网关无法确认精确编码版本时，新客户端会停止下载并提示更新。

- 腾讯下载传递精确编码选择，保留分集时长、画质、帧率和 HDR 要求。拒绝已确认的版本不符和无法确认的精确编码地址。
- 腾讯使用真实视频包覆盖时间检查完整性，不能用长音轨撑起的容器时长掩盖短视频。画质和各轨验收通过后才生成正式成品。
- 修复 CK 迁移失败误清本地凭证，以及导入尚未确认就提示成功的问题。迁移失败保留旧值，扫码成功清除旧签名，切换连接不会误清新凭证。
- 黄果重复密钥 URI 与不同 IV、轮换密钥及明文段混杂使用逐段解密；兼容只返回 hex 的旧网关。错误密钥和不支持的加密方式明确失败。

网关负责登录与取流，下载和验收在本机执行。完整 MAXPLUS 仍取决于源站授权和实际响应，不能把试看流转换成完整视频。

Windows 安装包与 macOS 两种芯片的 DMG 由 desktop 标签工作流生成；TUI 通过更新 main 或检出 v0.2.29 获取源码。
