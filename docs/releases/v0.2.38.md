# TUI v0.2.38 / 桌面端 desktop-v0.1.35

配套网关：v3.9.49。

本次把最新 IQCN 音轨界面和真实 AMP4 网关修复，与已完成的腾讯 IMAX 修复统一发布。

- 桌面端音轨按语言分组，显示标准 AAC、高码率 AAC、杜比音效等实际选择；左侧勾选下载，右侧选择默认播放音轨。
- 保留多音轨、全选、只选默认、键盘操作和窄窗口布局；设置未选音轨为默认时同时选中它，最后一条音轨不能取消。
- TUI 同步简化音轨名称，将“封装默认”提示改为“默认播放”。DASH/AMP4 交付细节不占额外选择项。
- 包含 desktop-v0.1.34 的腾讯 IMAX 修复：详情、画质、下载及任务重试保留 IMAX 参数，不混入普通编码枚举。
- 包含之前的优酷/腾讯完整发现菜单、二级栏目和卡片直接进入详情修复。

IQCN AMP4 后端配套修复在网关 v3.9.49。隔壁会话已完成相关测试与交互检查；本次合并发布不追加本地测试，沿用现有打包流水线。
