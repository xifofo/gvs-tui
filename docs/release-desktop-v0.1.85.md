# Desktop v0.1.85

补上 v0.1.84 漏掉的**配音（音频轨）与字幕轨**。

## 配音

- 画质页现在列出源站真实配音表（`日语（原声）` / `英语` / `西班牙语（拉美）` …），默认选原声。
  数据来自网关 `qualities` 的 `audios[]`（CR 每档配音是另一条 episode 版本）。
- 下载时把选中的配音作为 `audio=<locale>` 传给 `resolve`，网关换成对应版本 id 再取流——
  清单、assetId、内容密钥都会跟着换成那一档配音的，不是在同一条清单里切音轨。

## 字幕

- 画质页列出可用字幕（`简体中文` / `英语` / …），默认勾选中文，没有中文则勾英语。
- 字幕由源站单独发（签名直链，不需要认证头），不在 DASH 清单里。下载流程：
  1. `resolve` 回包里拿到 `subtitles[]`（网关随播放响应透传）；
  2. 只下勾选的语言，落到任务工作目录；
  3. MKV 输出用 `mkvmerge` 把字幕挂成独立轨（带语言、轨名、默认标记），失败只记提示，
     **不毁已下好的视频**。

## 兼容

- 旧网关（< v3.9.107）没有 `qualities.audios/subtitles`：画质页退回单条「自动」+ 无配音/字幕选择，
  下载行为与 v0.1.84 一致；
- 新网关缺字幕/配音字段时同理会退化成原行为，不会报错。

## 验证

- `bun test src/lib/`：961 项通过（新增：字幕表解析、勾选过滤、文件名净化、mkvmerge 参数；
  以及配音原声标注与默认选中）；
- `bun test app/src`：160 项通过；
- `bun run build`（tsc --noEmit + vite）与 `app` 的 `bun run typecheck` 通过。
