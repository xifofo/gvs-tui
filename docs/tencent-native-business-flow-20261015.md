# 腾讯操作记录与原生事件接入

2026-10-16 更新：普通 App/TUI 用户只需要正常登录腾讯 TV 账号。操作记录自动跟随搜索、详情、取画质和下载流程；账号页不再提供观测开关、JSONL 路径、采集模式或发送模式。升级前保存的关闭开关也不会阻止自动记录。

共用主进程客户端负责绑定账号和记录实际操作。下载任务保留入队时的账号；切换当前账号不会改变旧任务归属。旧网关缺少 report 接口、记录接口临时不可用时保留本机诊断，继续正常业务请求；账号认证、绑定失效、限频及风控拒绝仍停止流程。

这里的操作记录是本机/网关观测，不等于腾讯已经接收观看或广告事件。普通桌面流程现在已接入自动画像生成和 Qimei 注册；下载字节与下载耗时仍不会被转换成观看进度。本地注册联调通过，腾讯实网接收验收尚未完成，不能用隐藏入口或本地测试代替该验收。

## 自动生成画像（2026-10-16）

共用客户端正常建立 TV 绑定时，网关自动生成有序的基础广告画像，以及 Qimei 注册资料。客户端只记录脱敏生成状态，无须用户指定文件或手动开启采集。跨进程联调已经覆盖全新 TUI 和 Electron 配置的详情→取画质→下载流程，使用真实 Go 生成器、加密存储与客户端诊断。

匹配当前会话的虚拟 TV 档可自动生成完整注册资料，包括稳定 AndroidID/OpenUDID、设备/显示/网络声明、启动历史及原生预审；公开参考软件事实与账号私有标识分别保留来源，不标成真机采集。网关自动选择 SDK 应用标识，默认经本 Key 隧道注册，无需用户另外设置 App Key 或研究发送开关。成功返回的 Qimei 身份按账号和设备加密保存，后续画像直接复用；未知构建或缺项继续失败关闭，拒绝及送达不确定不自动重发。真实生成器、双层原生加密、WebSocket 隧道、配对响应、身份复用与拒绝停止已通过本地联调；尚无腾讯线上验收。详见[网关实现与验证范围](../../gateway/docs/analysis/tencent-tv-auto-profile-20261016.md)。

## 研究入口

外部采集文件和模板回放仅在明确设置 `GVS_TENCENT_NATIVE_RESEARCH=1` 的隔离研究进程中启用，继续使用配置中的事件源字段。普通进程即使保留旧 JSONL 配置也不会读取它；模板回放始终仅预览，旧的 send 配置不会让模板自动发送。手机已上传的镜像也始终仅预览。

研究协议和既有复核方法见[2026-10-15 网关接入记录](../../gateway/docs/analysis/tencent-tv-client-business-flow-20261015.md)。其中的用户配置入口描述是历史状态，以本文为准。免手机回放见[模板研究说明](tencent-native-phone-free-tui.md)。
