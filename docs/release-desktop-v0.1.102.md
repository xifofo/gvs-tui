# GVS 0.1.102

- PlutoFish 上传准备遇到节点暂不可用（`CLOUD_WAITING_WORKER`）时，自动等待并退避重试，不再立即把任务标记失败。
- 等待期间保留原任务和上传断点，并释放上传并发名额；节点恢复后继续原任务。不会自动重发结果不明的请求。
- 恢复暂停的上传时，核对暂停期间丢失回执的分片，再沿原断点继续。
- 自动归类支持更多常见音轨和 DVD 隔行片源，分辨率优先采用文件名标注。文件名与实际媒体规格不符会逐项说明；没有音轨的成品会提示检查文件。
- 修复校验收件循环空转的问题。

提供 Windows x64、macOS Apple Silicon 和 Intel 安装包。更新时保留配置、本地文件和发布记录。旧版已经失败的发布任务，需要在原任务上点击继续或重试，不要清空断点。

已完成共享发布引擎的离线回归；跨平台安装包及更新清单由发布工作流核验。离线验证不代表真实 115 上传或所有平台真机安装验收。
