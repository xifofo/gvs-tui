# TUI v0.2.72

Apple TV 下载修复：**音轨能选了、字幕会带上、进度不再瞬间跳满、长片最后一步不再卡十几分钟。**

## 变更

- **音轨列表**：Apple TV 的 probe 以前直接返回空音轨，下载只能按带宽盲选一条。
  现在把网关返回的全部配音（实测一部片 19–20 条语言）列出来，默认选中默认音轨，
  可以像其它平台一样切换。
- **字幕**：probe 返回全部字幕（实测 94 条），默认只选中 DEFAULT 那条，避免一次拖 90 多条。
- **下载按选择裁剪**：`resolve` 带上 `audio` / `subtitle` 序号，由网关只把选中的渲染
  写进给下载器的 master——Apple 所有配音的 URI 都叫 `stream/playlist.m3u8`，
  按文件名选不可靠。
- **进度**：多流下载时控制台进度会先被最短的流（音频）顶到 100% 然后卡住；
  下载阶段改用文件系统分段计数，控制台只在拿不到计数时兜底。
- **最后一步变快**：长片（>10 分钟）的完整性校验从「整片逐帧解码」改为抽 3 段
  （开头/中间/结尾）各解 20 秒。4K HDR 整片解码动辄十几分钟，这是合并解密后最慢的一段。

## 配套

网关 **v3.9.98**（多音轨/字幕可选、master 裁剪、进度与校验修复）。旧网关仍可下载，
但只能拿到默认音轨。
