# TUI v0.2.69 / Desktop v0.1.72

合并 PR #23（完善芒果元数据、音轨默认选择与 MKV GROUP 标签）。客户端侧改进，不要求新的 gateway 版本。

## 本次修改

- **芒果元数据与下载**：按精确 VID / clip ID 从公开 PC 分集目录补全缺失标题与正片时长；有有效码率及分集时长时估算大小。预检与下载共用请求头，保留平台明确提供的 Referer，避免自行添加网页 Referer 造成 HTTP 405。
- **音频语言与优酷 DTS:X**：芒果绑定 TMDB 后可在封装时修正单条内嵌音频的未知/通用英文标签；优酷优先使用所选音轨语言。补读 MP4 实际 DTS:X 编码与声道；自动选择遇到实际 10 声道 DTS:X 时，优先将同语言、已选择的 DDP 5.1 设为默认。
- **爱奇艺音轨选择**：国内版同语言、同内容类型有高码率 AAC 时，初始选择跳过对应标准 AAC；修正 IQ Cookie 路径中日语 ID 6 被误标法语的情况。
- **MKV GROUP**：在现有 MKV 封装中写入任务保存的发布组（旧任务回退到设置）；空值跳过，MP4 行为不变。
- **腾讯扫码与下载列表**：重新扫码时只有完整自定义设备参数才覆盖网关预设；长季集号使用可伸展列及换行，避免与下载状态重叠。
