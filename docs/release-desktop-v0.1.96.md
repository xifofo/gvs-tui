# Desktop v0.1.96

优化 PlutoFish 网盘目录选择，让选中保存位置和进入文件夹成为独立操作。

## 改动

- 单击文件夹即可选中，不再为了选择位置请求下一层目录；双击或点击右侧箭头进入。
- 底部显示实际保存路径，并明确区分“保存到选中的文件夹”和“保存到当前文件夹”。
- 创建作品、季目录时，以选中的文件夹作为父目录，已有目录继续复用。
- 保留 v0.1.95 的画质表字幕识别修复。

## 验证与安装

类型检查、桌面构建和隔离 Electron 目录选择回归已通过；合并远端后再次通过类型检查和腾讯画质选择测试。未进行真实网盘上传。

发布提供 Windows x64 安装包，以及 macOS arm64 / x64 DMG；附件包含更新清单和 SHA256 校验文件。安装包由 `desktop-v0.1.96` 标签触发 GitHub Actions 构建。
