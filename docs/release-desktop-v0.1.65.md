# TUI v0.2.63 / Desktop v0.1.65

配套网关 v3.9.80 与维护版 RE 0.6.0-gvs-iq.3，包含当前工作区全部客户端修改。

- IQ 账号设置支持国内/海外 Cookie 来源与 CDN 偏好，保持凭据由网关按账号保存；视频、音轨与重试固定取流来源。
- IQ 音轨语言修正、IP CDN 完整地址兼容及续传回归；维护版 RE 支持有边界的 SDT 描述、跨包重组和国内旧式 a0/vector/e1/content 分片。
- 优酷正确区分普通与 OTT 会员，下载前拒绝未登录/试看/画质或音轨不匹配；成品视频时长覆盖、HDR、音轨与命名核验更严格，防止短内容误标完成。
- 腾讯合并搜索优先保留可打开详情的 CID，来源点击直接进入对应详情；仅关键词入口显示相关搜索，避免误标可下载。
- 腾讯接入自动画像流程及原生事件诊断，保持账号作用域、覆盖说明及实际发送开关。
- 合并下载队列、质量选择与错误提示的全部本地回归修改。

验证：本地客户端库 851 项通过、20 项跳过、0 失败；另有桌面端类型检查、搜索导航及媒体相关测试。IQ 第8集实际视频和日语音轨下载/解码通过，IQCN 内嵌清单与 laiyuan 目录修复需要配套新网关。

TUI 从本标签源码安装（bun install、bun run dev）；Windows 源码自带经摘要验证的媒体工具。桌面安装包由 desktop-v0.1.65 发布页提供，维护版 RE 的独立各平台包由 managed-re-v0.6.0-iq.3 提供。
Windows：下载 GVS-Setup-0.1.65-x64.exe；macOS 按芯片选择 GVS-0.1.65-arm64.dmg 或 GVS-0.1.65-x64.dmg。三种安装包均内置新版 RE 与 IQCN 本地处理器。Mac 仍需系统 ffmpeg/gpac/mkvtoolnix；未签名应用首次按系统要求打开。
