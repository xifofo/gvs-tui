# 腾讯节目栏目

版本：TUI v0.2.10 / 桌面 App desktop-v0.1.3；配合 gateway v3.9.22。

- 从搜索进入腾讯节目：默认正片；TUI 用 `[` / `]` 切换栏目，桌面端点击栏目按钮。
- 粘贴具体播放页：定位到该 VID 所属栏目并选中目标视频。例如 `s4100gvoy9f` 是专访，不应当作正片第一集。
- 全选、反选、范围选择只操作当前栏目；切换栏目时清空选择，防止隐藏的采访/花絮被一起下载。
- 腾讯分段标题完整保留。各栏目使用独立序号，非正片下载到栏目子目录；上下/中片段不再共享同一文件名。
- 老网关没有栏目元数据时保留原有解析行为；建议两端一起升级。

实时样例《五十公里桃花坞 第5季》：正片 47 条、福持目标坞民 19 条、坞里都知道 11 条、专访 10 条、陪看 10 条。部分加更属于官方正片栏目，按官方归属保留。
