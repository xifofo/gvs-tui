# Desktop v0.1.82

在 v0.1.81（设备池布局修复）之上，补 **优酷音轨缺失** 的修复。

## 修复

用户报「优酷最后合并报错：下载的文件中没有音轨」。根因是下载下来的视频确实没有音轨，
而校验阶段才报错（`音轨校验失败：下载的文件中没有音频轨道…`）。

- **muxed 档**（酷喵 TV/App）：视频下载完先用 MP4Box 探测实际轨道；没有音频时自动改用源站返回的默认独立音轨；
- **separate 档**（帧享 HQ）：所选音轨播放列表 URL 缺失被跳过时，退回默认音轨；
- 两条路都拿不到 → **封装前**明确报错，不再拖到校验；
- 探测失败（容器非 MP4）保持原行为，避免误判。

## 配套

- TUI v0.2.77 同源修复（共用 `src/lib`）；
- 网关无需变更。
