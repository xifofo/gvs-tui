- 匹配 TMDB 后可在上传目录下点击「在网盘创建文件夹」，先选择上级目录并核对完整路径，再确认创建分类、作品及季目录。取消或失败保留原上传目标，成功后记住目录 ID；改名不重复创建，同作品换季默认复用作品目录。

- 腾讯画质预览优先使用明确的编码字段，数字 profile 不再冒充视频编码；已保存任务仍可匹配原 profile。成品按实际媒体规格修正名称，并沿用默认音轨。
- 上传按服务端返回的独立速率范围分配本地发送预算；低于 OSS 单连接限速下限的额度由本地预算控制，避免服务端拒绝限速请求头。
