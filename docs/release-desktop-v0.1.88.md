# Desktop v0.1.88

## PlutoFish 派生版本

- 匹配 TMDB 后可在上传目录下点击「在网盘创建文件夹」，先选择上级目录并核对完整路径，再确认创建分类、作品及季目录。取消或失败保留原上传目标，成功后记住目录 ID；改名不重复创建，同作品换季默认复用作品目录。
- 新建电影和剧集文件名使用作品名、年份、季集号、画质、来源、音频、视频的顺序，不附加平台单集标题；新配置默认发布组为 PFWEB，已有发布组和旧队列命名继续保留。
- 腾讯画质预览优先使用明确的编码字段，数字 profile 不再冒充视频编码；已保存任务仍可匹配原 profile。成品按实际媒体规格修正名称，并沿用默认音轨。
- 上传按服务端返回的独立速率范围分配本地发送预算；低于 OSS 单连接限速下限的额度由本地预算控制，避免服务端拒绝限速请求头。

验证使用模拟 Provider、回环 HTTP、本地合成媒体和隔离界面，不使用真实 115 账号或真实下载任务。Windows x64 安装包仍需在目标设备安装验收。

## 变更

- 内置 N_m3u8DL-RE 升到 **managed-re-v0.6.0-iq.4**（提交 `1bb9fc6`）：
  RE 的多初始化段拼接此前把音频输出为 `.m4a`（mp4/`ipod` 容器），mp4 不支持
  E-AC-3，Apple TV+ 默认音轨（16/JOC Atmos）会在拼接阶段 Failed；
- 现在 E-AC-3/AC-3/DTS 走 `.mka`（有视频时 `.mkv`），aac/mp3 仍为 `.m4a`；
- 回落封装输入识别补 `.mka` / `.mkv`；
- 界面与协议无变化。
