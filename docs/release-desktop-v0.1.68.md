# TUI v0.2.66 / Desktop v0.1.68

爱奇艺登录收敛为「扫码登录爱奇艺国内版」一条主路径，**IQ 海外版登录降级为可选**。配套 gateway v3.9.88（同一 API Key 下 iqcn 会话只读桥接为 iQ 内容的国内车道）与 v3.9.87（权益判决失败时降级国内车道）。

- 账号页把爱奇艺国内版排在 IQ 海外版之前；IQ 海外版标记为「可选」，文案说明仅 iq.com 独播内容需要。
- 登录说明写明：扫码登录爱奇艺国内版后，同一 Key 会自动作为 iQ 内容的国内车道凭据，不再需要单独填 IQ 账号。
- 不删除 IQ 海外版登录入口：iq.com 独播、国内站没有的内容仍需海外账号与其权益。
- 其它平台、搜索/详情/取流与下载流程未改动。

背景：有些 iQ 内容只在 iqiyi 车道放行（实测《朱色假面》E02 在海外 TV 车道被拒、在国内车道可取得 3840×2160 HEVC 播放计划），因此把国内登录作为默认，比维护两套账号更可靠。

验证：`bun test src/lib/providers.test.ts`、`bun test app/src/shared/provider-registry.test.ts` 全部通过；TUI `tsc --noEmit` 与 desktop `vue-tsc`+`tsc` 通过。未在真机 UI 上做点击验收；发布后需重新安装/重启客户端才能看到新排序与标记。发布不等于网关已升级，服务端请同步到 v3.9.88 及以上。
