# GVS 0.1.100

- 本地 Range 挑战按当前页和空闲槽连续处理，取消每轮固定 50 毫秒停顿，减少重复领取页尾的请求；最多仍有 16 个读取或回执任务在途。
- 回执完成后及时续接领取，正常成功摘要不再重复刷新发布任务；文件暂不可用的提示在恢复后仍会清除。
- 服务端通知暂不可用时，有任务后一秒补领，连续空闲才逐步退避到 15 秒；保留失败重放、断线恢复和共享 Key 的客户端隔离。

沿用现有 Range 领取及回传接口，本次优化不要求新增服务端接口。完全退出旧版后安装，保留原配置、本地成品及发布清单。

离线压测中，2,000 个挑战、40 毫秒模拟回执并保留一个持续慢回执，处理耗时约从 6.90 秒降到 5.57 秒，领取请求从 134 次降到 34 次；这不代表真实网盘交付提速幅度。

已验证客户端回归、类型检查和构建；未进行真实 115 联调或 Windows 真机安装验收。发布附件包含 Windows x64、macOS arm64/x64 安装包、更新清单和 SHA256 校验文件。
