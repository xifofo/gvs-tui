# TUI v0.2.53 / Desktop v0.1.54

需配合网关 v3.9.71 使用 Apple TV 新能力；原平台功能保持兼容。

- 修正 Bun 环境下 IQ 搜索超时定时器，避免补充目录请求挂起。
- 合入 PR #21：修复分集下载状态误判、画质页操作、IQ 下载/音轨/合流与代理可靠性，以及芒果清单与工具参数处理。
- Apple TV 新增发现页栏目、电影/剧集详情、全季分集和官方链接识别；账号页支持导入本人官网 Cookie、状态查询、指定作品权益验证和退出。
- Apple TV 使用网关授权后的 HLS 和内容密钥，本机直连 CDN、解密并封装；保留对应字幕组，默认选一条音轨。成品解码和分辨率验证通过后发布，名称采用实测媒体规格。
- 共用下载器支持网关返回的 HLS/MPD 文本，保留 Hami/Friday 的 DASH 多 KID 下载及清单签名过期处理。
- 旧网关没有 Apple TV 时显示明确升级提示；无可用设备或内容权益时失败关闭，不将加密/不完整文件标成完成。

真实 Apple TV 验收仅为 4K HDR 首音视频片段约 3.84 秒，并非整集验收。PRD 私钥始终留在网关，客户端只接收当前内容密钥并清理临时文件。此次安装包不包含账号 Cookie 或 DRM 设备文件。

Windows/macOS 安装包及自动更新清单由 desktop-v0.1.54 标签触发现有 Actions 生成；v0.2.53 为相同提交的 TUI 标签。
