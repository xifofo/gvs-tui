# GVS 0.1.99

- 秒传校验改为持续补充的有界流水线，最多同时处理 16 个读取或回执任务，慢回执不再阻塞整页待办。
- 同一成品共享指纹恢复任务，减少并发校验时的重复读取。
- 回执失败后回退扫描位置；旧分页响应不能跳过待重试任务，退出时等待进行中的任务收尾。

建议先升级配套 PlutoFish 服务端，再完全退出旧版并安装。保留原配置与本地成品；已有失败任务不会自动重试。

验证使用离线测试、类型检查和构建；未进行真实 115 联调或 Windows 真机安装验收。发布附件包含 Windows x64、macOS arm64/x64 安装包、更新清单和 SHA256 校验文件。
