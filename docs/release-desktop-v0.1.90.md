# GVS 0.1.90

- 发布失败保留阶段、业务码、HTTP 状态、115 数字错误码、请求编号和发生时间，并同步到 PlutoFish 后台的任务失败历史。成功重试不会抹掉此前诊断。
- 离线或上报失败时，诊断先落盘，重启后按原序号补报。历史补报单独等待恢复，不阻塞当前上传；未补报记录不会被清单清理删除。
- 历史复用文件明确失效后，沿用原任务重新初始化上传。普通核验拒绝显示具体阶段和错误码；未知结果、授权和限流不触发重复上传。
- 自动识别服务端诊断能力，旧服务端继续使用原任务上报格式。请先升级 PlutoFish 服务端，再升级客户端以获取后台完整历史。

已通过共享发布引擎离线回归、桌面端类型检查和构建。安装包由 GitHub Actions 构建，提供 Windows x64 和 macOS arm64/x64；未进行真实 115 上传验收，macOS 包未签名、公证。
