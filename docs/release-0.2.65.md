# TUI v0.2.65 / Desktop v0.1.67

修复自动画像注册状态误拦截腾讯搜索、详情和播放的回归。配套 gateway v3.9.82；客户端也兼容 v3.9.80/81 的旧绑定回包。

- 画像注册的 blocked、rejected、pending、送达不确定或响应未确认只停止对应上报，不再将已认证的业务绑定当作腾讯播放风控。
- 搜索、详情和播放继续携带有效账号绑定；实际业务返回登录失效、403/429 或 em=93/94 时，仍停止业务流程。
- 在画像停止状态下不追加观测/原生事件发送，注册账本仍保留并禁止自动重发；不删除设备身份、不要求重新扫码。
- 修复版必须重启 App，清除旧进程中已被错误设置的业务停止状态。

本地真实 HTTP 回归覆盖旧/新绑定信封下的搜索→详情→播放，以及实际风控后的阻止；相关四文件 54 项测试通过。配套网关验证画像持久化停止记录不破坏业务绑定、不新增注册请求。未把画像身份注册标为已成功。

本轮未为复现而请求线上搜索/播放或重新注册；依据本机 2026-10-17 17:15 日志与本地合成回包复现。发布后客户端可独立兼容已部署旧网关，服务端也建议同步升级。
