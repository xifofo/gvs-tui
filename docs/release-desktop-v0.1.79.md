# Desktop v0.1.79

配套网关 **v3.9.101**：设备文件支持多只（设备池），并按等级自动挑。

## 设备文件（设置 → 设备文件）

- 每个系统（Widevine / PlayReady）现在可以**存多只**：点「继续上传」追加，列表里逐只显示等级、名称；
- 每只旁边有「删除」，只删这一只，其它设备保留；
- 池满 8 只时上传按钮禁用；
- 旧的单只文件无需重传：网关以 `legacy` 条目继续读取，出现在列表里。

## 行为变化

- 4K / 需要 L1 的内容会自动挑 L1，SD 内容可以用 L3，不再「只能传一只 L1」；
- 某只设备被源站拒（如 `-1021`），网关自动换池里的下一只重试；
- 许可拒绝提示细分：`-1021` 说设备被拒，`-1004` 说账号设备名额满（Apple 上限 6 台）。
