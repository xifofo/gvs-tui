# GVS 0.1.92

- 修复已有成品因缺少媒体规格而无法上传的问题：点击「重试上传」会重新检测原本地文件，保存实际分辨率、编码、音轨和大小，再继续上传，无需重新下载。
- 检测时显示「检测媒体规格」。文件丢失、为空、检测中改变或与原上传断点不符时明确提示；暂停和取消不会写入迟到结果，重启不会自行重试失败任务。
- 同步上游 TUI v0.2.85 的下载库：Apple TV+、Disney+、Crunchyroll 下载完成后记录实测规格；Apple TV+ 使用 ATVP 来源标签，补全简繁字幕轨名与语言标签；改善 Crunchyroll 字幕出口和芒果清单重试、串行下载及限流提示。
- 完善自动上传开关、已有成品手动上传和改名／移动后重新关联文件；优化大量下载历史下的进度刷新，PlutoFish 短暂断线时保留页面并自动重连。
- 缺少预览编码时支持匹配唯一发布版本，并复核已知 E-AC-3 解码兼容错误，保留原音轨。

上游同步后的 1,443 项回归通过；补检修复后的 264 项发布端／终端回归、Electron 重试与重启流程、本地生成 MKV 的实际检测、Apple TV+ 本地媒体夹具、类型检查及两端构建通过。网络回执使用模拟接口，未进行真实 115 上传或 Windows 真机验收。

Windows x64、macOS Apple Silicon 和 Intel 安装包由 GitHub Actions 构建并统一发布。已有文件仍在原路径的用户，更新后可直接对失败任务点击「重试上传」。
