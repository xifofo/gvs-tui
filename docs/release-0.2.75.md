# TUI v0.2.75

配套网关 **v3.9.101**：设备文件改成设备池，许可拒绝的提示细化。

## 变更

- **文案表同步（78 条）**：新增
  - `DRM_DEVICE_REJECTED`（源站 `-1021`）→「平台拒绝了这台设备的换钥请求（设备被吊销或账号受限）…」
  - `DRM_DEVICE_LIMIT_REACHED`（源站 `-1004`）→「账号的换钥设备名额已满（Apple 上限 6 台）…」
  - `DRM_CLIENT_DEVICE_LIMIT`（池满 8 只）
  用户不再只看到一个 `-1021` / 请求失败。
- **设备池**：客户端类型支持 `entries[]` 与 `deleteDRMOne(system, id)`，配合网关按等级选设备、
  一只被拒自动换下一只。TUI 没有设备文件界面（在 Desktop 管理），下载侧自动受益。

## 配套

网关 v3.9.101（旧网关仍可用，只是没有设备池与细分文案）。
