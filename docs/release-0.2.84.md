# TUI v0.2.84

配套网关 **v3.9.118**。修 **芒果 CDN 拒绝/限流容错**、**Crunchyroll 成片没字幕**，并把
**Apple TV+ 简繁字幕**在合轨后写上轨名备注。

## 变更

### 芒果（MGTV）

- 清单读取撞上 405 时自动重试，修「沉浸版第 2 集」这类偶发失败；
- 清单被 CDN 拒绝时重取播放地址再试；芒果任务改为串行化，避免同一出口并发自撞；
- 出口被 CDN 限流时给准确提示，并让芒果任务进入冷却；
- 清单请求改用非浏览器 UA、不带 Referer —— 实测这才是 403/405 的触发条件。

### Crunchyroll

- 字幕下载走媒体同一条出口（含桌面端 native 通道），修「成片没字幕」；
- 账号并发会话已满时把错误显示出来，不再静默退回「自动」；
- 整文件型 DASH 下载期间显示真实速度，不再长时间 0 B/s；
- 音轨被源站错标成 `eng` 时用所选原声 locale 纠正；
- 默认勾选简繁中文、简体标为默认轨，画质页字幕文案改正。

### Apple TV+ / 合轨封装

- 合轨后给简繁字幕写轨名备注（`简体中文` / `繁体中文`）：ISO 639-2 把两种字形都压成
  `chi`，此前播放器里两条轨只显示成同一个「中文」；
- 成片字幕轨写入轨名与默认标记；字幕语言标签改用 `zh-Hans` / `zh-Hant`；
- 视频轨跟随主语言打标签（与 IQ 等平台成品一致），已有显式语言的视频轨不动；
- 发布源标签用 `ATVP`，不再落到 `APP`；
- CR / Apple TV+ / Disney+ 完成后也记录成片实测规格。

### 其他

- 新增 `scripts/check-idle-before-install.sh`：安装前先确认没有下载/封装任务在跑。

## 验证

- `bunx tsc --noEmit` 无错误；
- `bun test`（受影响的 8 个单测文件）**116 pass / 0 fail**；
- 合轨集成测试在本机缺 ffmpeg/mkvmerge 时按设计跳过（不是失败）；
- main 合并推送后的 CI（tui）通过。
