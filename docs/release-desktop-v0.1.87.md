# Desktop v0.1.87

## PlutoFish 派生版本

- PlutoFish 明确声明支持双文件上传时才启用并发；旧服务端继续使用单文件兼容模式并显示提示。
- 115 开放接口明确返回访问受限时暂停同账号上传队列，至少冷却 15 分钟后手动恢复；重启和自动重连不能绕过。15 分钟是应用保护策略，不是供应商承诺的解封时间。
- OSS 暂时繁忙与上述账号访问受限分开处理。新分片会话不再查询空列表，已有会话续传仍核对分片。
- 已就绪上传复用服务端核验回执；等待凭据时取消任务，不会在响应到达后继续发起 OSS 请求。

验证使用模拟 Provider、回环 HTTP 和隔离界面，不使用真实 115 账号。Windows x64 包需在目标设备安装验收。
